- Source page: https://clashofclans.fandom.com/wiki/Scenery
- Retrieved: 2026-08-14
- Scope: 69 Home Village sceneries represented by 71 source images
- Download mode: original source files (`format=original`), without resizing or recompression
- Total local size: 276.82 MiB
- Full and close-up originals are both retained for Clash of Dragons and Year of the Snake

Run `tools/download-home-village-sceneries.ps1` to refresh the collection from
the Home Village gallery. The script discovers the current gallery through the
MediaWiki API, verifies each file's real container format, writes `manifest.json`,
and updates the website scenery catalog while preserving calibrated grid data.
